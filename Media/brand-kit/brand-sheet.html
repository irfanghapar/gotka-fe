Brand / Logo system v1.2 — subline colour aligned to the live site

Gotka Technologies

The mark is a rack unit: a faceplate badge carrying a squircle G and a live status LED — the same language as the server rack on the website hero. The "TECHNOLOGIES" subline now uses the same neutral slate-grey as the production header and footer, instead of a brand-colour tint. Every letter is drawn as vector paths, so the files need no fonts and scale from favicon to billboard.

07 · Rules of use

Keep the signal clean

Clear spaceKeep empty space around the logo equal to the badge's LED-to-edge distance (about ¼ of the badge) on all sides.
Minimum sizeHorizontal lockup: 140 px / 35 mm wide. Below that, switch to the icon alone.
The LED is the accentOne green dot per placement. It always sits top-right on the badge, or after the A in the bare wordmark.
Don'tRecolour the letterforms, stretch the lockups, add gradients or shadows, or place the colour version on busy photography — use mono instead.
