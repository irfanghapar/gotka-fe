# Gotka Technologies — Brand Kit v1.2

The complete identity package: logo files in every format, colour palette
for design tools, typography specs, social assets, and the brand guidelines PDF.

**What's new in v1.2** — the logo's "TECHNOLOGIES" subline colour now matches
what's actually live on the website: a neutral slate grey (`#41566A` on light
backgrounds, `#7E93A6` on dark) instead of the earlier petrol/green treatment.
The reverse (dark-background) lockup's wordmark is also now pure white,
matching the site footer exactly. Every SVG, PNG, WebP, the brand sheet, and
the guidelines PDF have been regenerated from the corrected source.

## Start here
- **gotka-brand-guidelines.pdf** — the 8-page guidelines: the mark, lockups,
  clear space, colour, typography, usage rules. Share this with any designer,
  printer or agency.
- **brand-sheet.html** — interactive one-page brand sheet (open in a browser).

## Ground rules (short version)
Use the SVG masters whenever you can. Clear space = ¼ of the badge on all
sides. Minimum width 140 px for the horizontal lockup — below that, use the
icon. One green LED per placement. The "TECHNOLOGIES" subline is always
neutral slate grey, never a brand colour. Never stretch, recolour, add
effects, or re-set the wordmark in a font.
